# Provided Passage Sentence and Boundary Model V0.1

문장은 입력 순서대로 `s1`, `s2`, … ID를 갖고 정확한 원문 `start`, `end`, `text`를 보존한다. 문장 경계는 `b0`부터 시작한다.

- `b0`: 첫 문장 앞
- `b1`: s1 뒤와 s2 앞 사이
- 마지막 boundary: 마지막 문장 뒤

분리기는 `.`, `?`, `!`, 문장 끝 따옴표·괄호를 처리하며 소수점과 `Dr.`, `e.g.` 등 제한된 일반 약어를 문장 끝으로 오인하지 않는다. 이는 결정적 MVP 분리기이며 사람이 Preview에서 결과를 확인한다.

문장 삽입에는 경계가 최소 5개 필요하다. AI가 반환하는 후보 5개는 원문 offset 순서여야 하며 각 ID가 source boundary에 존재해야 한다. 앱은 원문에 ①~⑤를 저장하지 않고 렌더링 때만 표시한다.
