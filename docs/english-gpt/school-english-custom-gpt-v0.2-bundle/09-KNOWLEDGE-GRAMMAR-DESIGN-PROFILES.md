# School English Grammar Design Profiles V0.2

이 문서는 Provided Passage V0.2의 `grammarDesignProfile`을 해석하는 상세 Knowledge다. 세 학교 시험 PDF의 텍스트 레이어와 페이지 렌더링을 함께 확인한 구조 감사 결과를 사용한다. OCR·외부 사전·외부 API는 사용하지 않았다. 정답지는 제공되지 않았으므로 아래 문법 판정은 공식 정답 전사가 아니라 원문 구조에 근거한 출제 구조 분석이다.

## 1. 관찰 범위

- 2025학년도 고1 1학기 중간고사: 객관식 어법 7문항, 서술형 교정 1문항
- 2025학년도 고1 1학기 기말고사: 객관식 어법 4문항
- 2025학년도 고1 2학기 기말고사: 객관식 어법 2문항
- 합계: 객관식 13문항, 서술형 1문항

객관식 13문항 가운데 11문항은 다섯 밑줄 중 하나의 오류를 찾는 형식, 1문항은 같은 용법 비교형, 1문항은 옳은 표현 조합형이었다. 현재 V0.2는 첫 형식만 `controlled_error_variant`로 직접 생성한다. 비교형·조합형·서술형은 관찰 근거일 뿐 생성 허가가 아니다.

## 3. 프로필 값

### `school_exam_balanced`

기본 권장값이다. 원문에 실제로 존재하는 후보 중 관계사·절, 수 일치, 동사·준동사, 능수동, 대명사·지시 관계를 가능한 한 분산한다. 다섯 범주를 의무적으로 하나씩 채우는 quota가 아니다. 같은 범주를 반복하는 편이 더 명확하면 근거 명확성을 우선한다.

### `clause_relations`

관계대명사·관계부사, 동격 `that`, 절의 완전성, 선행사 범위를 우선한다. `that`이라는 표면 문자열만 보고 분류하지 말고 뒤 절의 결손 성분과 앞 명사의 역할을 확인한다.

### `verb_and_nonfinite`

유한 본동사 유무, to부정사·동명사·분사, 목적격 보어, 병렬 동사 구조를 우선한다. 동사처럼 보이는 철자만 고르지 말고 문장 안의 문법 기능을 확인한다.

### `agreement_voice_reference`

실제 주어와 동사의 수, 능동·수동, 대명사·재귀대명사의 선행사와 수를 우선한다. 전치사구·삽입구 안의 가까운 명사에 끌려가지 않는다.

### `source_best_fit`

범주 분산보다 원문에서 가장 명확하고 유일하게 판정되는 다섯 표적을 우선한다. 원문이 짧거나 특정 구조가 제한적일 때 사용한다.

## 4. 생성 알고리즘

1. Request의 `questionType`, `grammarMode`, `requiredStem`, choices 기호를 먼저 고정한다.
2. 원문의 sentence ID와 offset으로 문법 후보를 찾는다.
3. 각 후보가 외부 지식 없이 하나의 규칙으로 판정되는지 확인한다.
4. 프로필 순위는 근거가 확인된 후보 사이에서만 적용한다.
5. 원문 순서의 서로 겹치지 않는 정확한 표적 다섯 개를 선택한다.
6. 한 표적의 `presentedForm`만 최소 변형해 오류로 만들고 나머지 네 표적은 원문 형태를 보존한다.
7. `testedSpan.text === sourceForm`, testedSpan은 evidenceSpans 중 하나, answerIndex는 그 배열 순번이어야 한다.
8. 선택 프로필에 충분한 후보가 없으면 `source_best_fit`처럼 실제 근거가 있는 후보를 사용한다. 유효한 Request를 프로필 불충족만으로 거부하지 않는다.

## 5. 정확한 범위 원칙

- 한 토큰만으로 판정할 수 없으면 동사구·부정사구·수동태 구성 등 필요한 전체 범위를 사용한다.
- 관계사 문항은 선행사와 절 구조를 evidence로 확인하되 실제 밑줄 범위는 시험 표식에 필요한 최소 표현으로 둔다.
- 하이픈·철자 손실, 단순 어휘 의미 교체, 희귀어는 어법 오류로 사용하지 않는다.
- `①~⑤`, `ⓐ~ⓔ`, `(a)~(e)`는 Request가 itemId별로 지정한 choices 배열을 그대로 사용한다.
- 같은 공유 원문의 다른 문항으로 밑줄이나 변형을 전파하지 않는다.

## 6. Corpus·Vocabulary 근거 사용

Corpus Engine의 syntax·discourse 및 어휘 결과는 분포를 설명하는 보조 근거다. `observed_surface`는 시험 표면 관찰, `observed_reference`는 EBS 등재 관찰, 의미·절대 난이도는 `unsupported`로 분리한다. 통계 평균을 문장별 할당량으로 사용하거나 EBS 등재를 중요도·난이도로 해석하지 않는다. 원문에 있는 하이픈과 다중어 경계는 보존한다.

## 7. 출력 전 검사

- 프로필을 원문에 없는 구조를 만드는 명령으로 오해하지 않았는가?
- 지원하지 않는 비교형·복수 정답 조합형·서술형으로 바꾸지 않았는가?
- 다섯 표적이 서로 겹치지 않고 원문 순서이며 정확한 구 경계를 보존하는가?
- 정답 하나만 문법적으로 틀리고 나머지 넷은 성립하는가?
- 원문, sourceForm, evidence text는 불변이고 오류는 presentedForm에만 있는가?
- question.stem과 choices가 Request와 글자 단위로 같은가?
- grammarTarget이 우선값일 때 원문에 없다는 이유만으로 거부하지 않고 source-evidenced fallback을 사용했는가?

하나라도 충족하지 못하면 추측한 문항을 출력하지 않는다. 다만 프로필 자체는 선호값이므로, 원문 근거가 충분한 다른 지원 구조가 있으면 그 구조로 안전하게 전환한다.
