# 수능형 전용 GPT 설정 순서

## 1. 새 GPT 만들기

ChatGPT의 GPT 만들기 화면에서 새 GPT를 만든다. 제작 화면의 대화식 빌더보다 **구성(Configure)** 화면에서 아래 항목을 직접 입력하는 편이 안정적이다.

- 이름: `수능형 영어 문제 제작 연구소`
- 설명: `평가원 수능 영어 읽기 18~45번의 구조를 참고해 설계안을 협의한 뒤 앱 호환 JSON을 만드는 전용 GPT`

## 2. Instructions 입력

[CSAT_GPT_INSTRUCTIONS.md](./CSAT_GPT_INSTRUCTIONS.md)의 구분선 아래 전체 내용을 Instructions에 붙여 넣는다.

앱이 실행 중이라면 **수능형 GPT 지침 복사** 버튼으로 같은 핵심 규칙을 복사할 수도 있다. 문서판은 GPT 설정용으로 더 간결하며, 앱 버튼판은 번호별 카탈로그까지 포함한다.

## 3. Knowledge 업로드

다음 순서로 업로드한다.

1. [CSAT_STYLE_MANUAL.md](./CSAT_STYLE_MANUAL.md)
2. [csat-output-schema.json](./csat-output-schema.json)
3. 평가원 시험지 PDF 11개
   - 2023 6월, 2023 9월, 2023 수능
   - 2024 6월, 2024 9월, 2024 수능
   - 2025 6월, 2025 9월, 2025 수능
   - 2026 6월, 2026 수능

PDF는 문제 형식 확인용이고 제작 매뉴얼이 규칙의 단일 기준이다. 정답·해설 PDF는 현재 패키지에 필요하지 않다.

## 4. 기능 설정

- 웹 검색: 끔
- 이미지 생성: 끔
- Canvas: 끔
- 코드 인터프리터 및 데이터 분석: 켬
- Actions: 사용하지 않음
- 외부 앱/API: 연결하지 않음

데이터 분석 기능은 단어 수, JSON 구조, 정답 분산을 자체 점검하는 데만 사용한다.

## 5. 대화 시작 문구

다음 네 개를 권장한다.

- `앱에서 복사한 수능형 제작 프롬프트를 붙여 넣겠습니다.`
- `여러 문항 카드의 세트 제작 설계안부터 만들어 주세요.`
- `승인 전에는 JSON을 만들지 말고 카드별 설계를 보여 주세요.`
- `기존 JSON을 검사하고 앱 호환 수정 JSON으로 돌려주세요.`

## 6. 비공개 테스트

공유하기 전에 [GPT_TEST_CASES.md](./GPT_TEST_CASES.md)의 1~6번을 실행한다. 특히 첫 응답이 JSON이 아닌 `[세트 제작 설계안]`인지, 일반 지문이 한 문단인지, 승인 후 JSON 밖의 문장이 없는지 확인한다.

## 7. 공유와 앱 연결

테스트가 끝난 뒤 링크가 있는 사용자만 사용할 수 있도록 공유한다. 생성된 `https://chatgpt.com/g/...` 주소를 보관한다.

링크를 영어 문제 제작 연구소의 수능형 메뉴에 연결하려면 나중에 사용자 요청에 따라 `public/english-gpt-config.json`의 `csat` 값만 채운다. 현재 파일의 빈 값은 그대로 두며, 새 링크를 받기 전에는 임의 주소를 넣지 않는다.

## 8. 실제 사용 순서

1. 영어 문제 제작 연구소에서 수능형 문항 카드를 구성한다.
2. **제작 프롬프트 생성·복사**를 누른다.
3. 전용 GPT에 붙여 넣는다.
4. GPT가 제시한 `[세트 제작 설계안]`을 검토한다.
5. 수정할 카드 번호와 변경 사항을 말한다.
6. 전체 설계가 만족스러우면 `승인. 이대로 JSON 생성`이라고 입력한다.
7. 나온 JSON 전체를 앱의 AI 결과 입력란에 붙여 넣는다.
8. 최신 결과 검사 후 경고가 있으면 재검토 프롬프트를 복사해 같은 GPT에 보낸다.
9. 수정 JSON을 다시 가져오고 검사한다.
