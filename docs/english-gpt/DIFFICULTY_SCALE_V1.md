# 영어 문항 난이도 8단계 기준 V1

수능형과 내신형 세트의 사용자 난이도는 `매우 쉬움 / 쉬움 / 약간 쉬움 / 보통 / 약간 어려움 / 어려움 / 매우 어려움 / 최상`의 8단계다. 앱은 저장 호환성을 위해 1~8 숫자를 저장하지만, 제작 프롬프트에는 단계 이름과 다음 네 축을 함께 전달한다.

- 대상 학생 수준과 시험 맥락
- 정답 근거의 위치와 개수
- 필요한 추론 단계와 관계 재진술 정도
- 오답의 매력도와 정답을 가르는 결정적 차이

`보통`은 단순한 중간 숫자가 아니다. 수능형에서는 평균적인 수능 2점 또는 무난한 3점 문항, 내신형에서는 일반적인 학교 시험의 평균 난도로 해석한다. 난도가 높아질수록 여러 근거의 종합, 추론 거리, 범위·인과·주체를 미세하게 왜곡한 오답을 강화한다.

난도 상승을 위해 교육과정 밖 배경지식, 불필요한 희귀어, 과도한 장문, 번역투, 복수 정답 가능성이나 모호성을 사용해서는 안 된다. `최상`에서도 정답 유일성과 지문 근거만으로 풀 수 있다는 원칙을 유지한다.
