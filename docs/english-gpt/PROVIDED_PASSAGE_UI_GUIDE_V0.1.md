# Provided Passage UI Guide V0.1

1. 내신형 문항 설계에서 세트를 연다.
2. 자료 작성 방식을 `기존 지문 사용`으로 바꾼다.
3. 내용 일치·불일치 또는 문장 삽입을 선택한다.
4. 선택적으로 제목을 입력하고 영어 원문을 붙여 넣는다.
5. 내용 일치에서는 선지 언어를, 두 유형 모두에서 생성 영어 어휘 수준을 선택한다. 문장 삽입의 선지 언어는 비활성화된다.
6. 문장 분리 Preview와 source fingerprint 상태를 확인한다.
7. 문장 삽입은 적격 경계가 5개 이상인지 확인한다. AI 응답의 후보 경계는 정확히 5개여야 한다.
8. 프롬프트를 생성해 외부 AI에 붙여 넣고 설계안을 승인한다.
9. 승인 후 받은 전용 JSON만 앱에 가져온다.

V0.1은 내신형 세트 하나에 provided 문항 하나만 지원한다. `새 자료 작성`으로 돌아가면 기존 generated 흐름을 사용한다. 수능형 문항 설계에는 이 선택 UI를 표시하지 않는다. 앱은 원문을 자동 교정하지 않는다.
