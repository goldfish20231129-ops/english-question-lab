# 수능형 검증 GPT 테스트

## 기본 통과

- 모든 문항을 독립적으로 풀고 선지별 판정을 반환한다.
- 정확히 하나의 `correct`, 나머지는 `incorrect`이며 기존 정답·해설과 일치한다.
- 명확한 문제가 없다면 `findings`는 빈 배열이다.

## 필수 오류 검출

1. 검증 정답과 기존 정답이 다른 문항
2. 두 선지가 모두 정답이 될 수 있는 문항
3. 한 선지가 `ambiguous`인 문항
4. 해설이 여러 인물을 가리킨다고 인정하면서 하나를 정답으로 확정한 44번
5. (a)~(e)의 지칭 대상 분포가 2:1:1:1 또는 3:2인 44번
6. 본문 다음 문장이 정답 선지를 거의 그대로 반복하는 빈칸 문항
7. 관사나 수일치 오류만으로 정답을 고를 수 있는 빈칸 선지
8. 연결어 하나만으로 순서가 즉시 결정되는 고난도 순서 문항
9. 요약문의 (A)·(B)가 원문에서 그대로 복사된 문항
10. 기존 정답은 맞지만 오답 사유가 지문과 모순되는 문항

## 출력 안정성

- 모든 문항 ID가 정확히 한 번씩 포함되어야 한다.
- 알 수 없는 세트·카드·문항 ID를 만들지 않는다.
- `targetId`와 `sourceFingerprint`를 변경하지 않는다.
- 수정된 문제 JSON이나 마크다운을 반환하지 않는다.
